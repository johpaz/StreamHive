# StreamHive — Hive Play

Identidad basada en la propuesta 1 aprobada: celda de panal con reproducción en espacio negativo y hombro lateral asimétrico. El símbolo se reconstruyó en SVG para la interfaz y los tamaños pequeños.

- `streamhive-mark.svg`: símbolo principal verde, fondo transparente.
- `streamhive-mark-white.svg`: símbolo blanco, fondo transparente.
- `streamhive-logo.svg`: composición horizontal para fondos oscuros; tipografía Manrope con alternativas locales.
- `icon-192.png` y `icon-512.png`: iconos para el manifiesto web.
- `favicon-32.png`: alternativa PNG del favicon.
- En la raíz pública: `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` y `site.webmanifest`.

Colores: verde `#B5ED7D`, fondo `#0C1015`, panel `#131820`, texto `#EDF2F7`. Mantener espacio libre alrededor del símbolo y conservar sus proporciones. En la app, el componente `BrandMark` sirve el símbolo compartido; el nombre permanece como texto accesible.

Los logos que cada productor sube para sus emisiones siguen siendo personalizables.
